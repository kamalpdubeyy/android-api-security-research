# Project Reports

This folder contains project documentation, technical reports, and security analysis related to the Android API Security Research project.

## Included Documents
- MSc project report
- Security testing findings
- Vulnerability analysis
- Comparative evaluation of secure vs insecure APIs
- Risk assessment documentation

## Topics Covered
- Broken Object Level Authorization (BOLA)
- Broken Authentication
- Sensitive Data Exposure
- JWT-based Security Controls
- OWASP API Security Principles
